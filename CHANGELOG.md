# Changelog

## [0.1.0]

- First public release: CLI (`agentstatus`) and menu bar panel in one notarized app.
- `agentstatus setup` connects Claude Code, Codex and Grok (experimental) with diff and confirmation.
- Install via Homebrew from this repository: `brew tap timohone/agentstatus https://github.com/Timohone/agentstatus`, then `brew install --cask timohone/agentstatus/agentstatus`.
